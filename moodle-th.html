🎓รู้จัก Moodle
โครงสร้างรายวิชา ความสามารถ บทบาท ประวัติ เริ่มใช้งาน

ห้องเรียนที่เปิดไว้บนเว็บ ให้เข้าได้ทุกเวลา

Moodle เป็นระบบจัดการการเรียนรู้ (LMS) แบบโอเพนซอร์สที่ใช้ได้ฟรี โรงเรียน มหาวิทยาลัย และบริษัทนำไปติดตั้งเพื่อสอนออนไลน์ ครูแจกเอกสาร รับงาน ออกข้อสอบ ตั้งกระทู้ถกเถียง และดูคะแนนได้ในที่เดียว

ชื่อ Moodle ย่อมาจาก Modular Object-Oriented Dynamic Learning Environment แปลตรงๆ ว่า สภาพแวดล้อมการเรียนรู้แบบไดนามิกที่แยกเป็นโมดูลและเน้นวัตถุ

🧩ซอฟต์แวร์ที่ติดตั้งเอง ไม่ใช่บริการที่ต้องเช่า

Moodle เขียนด้วย PHP ทำงานบนเว็บเซิร์ฟเวอร์ทั่วไปร่วมกับฐานข้อมูล เช่น MySQL, MariaDB หรือ PostgreSQL ซอร์สโค้ดเผยแพร่ภายใต้ GNU General Public License ทุกคนจึงดาวน์โหลด ติดตั้ง แก้ไข และแจกจ่ายต่อได้โดยไม่เสียค่าใช้จ่าย

สถาบันเลือกติดตั้งบนเซิร์ฟเวอร์ของตัวเอง ใช้ผู้ให้บริการโฮสติ้งที่เป็นพันธมิตร หรือใช้ MoodleCloud ก็ได้ ผู้เรียนและครูเข้าผ่านเบราว์เซอร์ หรือผ่านแอป Moodle บน Android และ iOS ซึ่งดาวน์โหลดเนื้อหาไว้เรียนแบบออฟไลน์ได้

Moodle แยกเป็นโมดูล จึงต่อยอดด้วยปลั๊กอินได้เกือบทุกส่วน ทั้งกิจกรรมแบบใหม่ ธีม วิธีเข้าสู่ระบบ รายงาน และการเชื่อมกับระบบอื่น

🧱ทุกรายวิชาประกอบด้วยหัวข้อ ทรัพยากร และกิจกรรม

หน้ารายวิชาแบ่งเป็นหัวข้อ มักแบ่งตามสัปดาห์หรือตามเรื่อง ครูใส่ของสองประเภทลงในแต่ละหัวข้อ

ทรัพยากร: สิ่งที่ผู้เรียนอ่านหรือดู

  • 📁 ไฟล์PDF สไลด์ เอกสาร หรือวิดีโอที่อัปโหลดไว้ในรายวิชา
  • 📃 หน้าหน้าเว็บที่เขียนในตัวแก้ไขข้อความของ Moodle โดยตรง
  • 📖 หนังสือเนื้อหาหลายหน้าแบ่งเป็นบท เหมือนตำราออนไลน์เล่มสั้น
  • 🔗 URLลิงก์ไปเว็บไซต์หรือวิดีโอภายนอก
  • 🗂️ โฟลเดอร์รวมไฟล์หลายไฟล์ไว้แสดงด้วยกัน

กิจกรรม: สิ่งที่ผู้เรียนลงมือทำ

  • 📝 งานที่มอบหมายผู้เรียนอัปโหลดไฟล์หรือพิมพ์ตอบในหน้าเว็บ ครูตรวจและให้ข้อเสนอแนะ
  • 🎯 แบบทดสอบตรวจให้อัตโนมัติจากคลังข้อสอบ มีทั้งปรนัย จับคู่ เติมคำ และเรียงความ
  • 💭 กระดานสนทนากระทู้สำหรับถามตอบ อภิปราย และประกาศ
  • 🤝 เวิร์กช็อปผู้เรียนส่งงานแล้วประเมินงานของเพื่อนกันเอง
  • 🎮 H5Pเนื้อหาโต้ตอบได้ เช่น วิดีโอแทรกคำถาม ลากวาง และแฟลชการ์ด

🧰เครื่องมือที่ครูและผู้ดูแลระบบใช้บ่อยที่สุด

📊สมุดคะแนน

คะแนนจากทุกกิจกรรมไหลมารวมในที่เดียว จัดเป็นหมวด ถ่วงน้ำหนัก ตั้งสเกล และแปลงเป็นเกรดตัวอักษรได้

✅ติดตามความคืบหน้า

เครื่องหมายถูกบอกว่าผู้เรียนทำอะไรเสร็จแล้ว ครูกำหนดเงื่อนไขได้ เช่น “เปิดไฟล์นี้แล้ว” หรือ “ได้คะแนนอย่างน้อย 60%”

🔓จำกัดการเข้าถึง

เปิดเนื้อหาต่อเมื่อถึงวันที่กำหนด ได้คะแนนตามเกณฑ์ หรือทำกิจกรรมอื่นเสร็จแล้ว ผู้เรียนจึงเดินตามเส้นทางที่ครูวางไว้

🏅เหรียญและเกียรติบัตร

มอบเหรียญเมื่อผู้เรียนทำสำเร็จ เหรียญใช้มาตรฐาน Open Badges ผู้เรียนจึงนำไปแสดงบนเว็บอื่นได้

🌏ภาษาของหน้าจอ

ชุดภาษารองรับมากกว่า 100 ภาษา รวมถึงภาษาไทย และผู้ใช้แต่ละคนเลือกภาษาของตัวเองได้

🔌เชื่อมต่อระบบอื่น

LTI เชื่อมเครื่องมือภายนอก SCORM นำเข้าบทเรียนอีเลิร์นนิง และเว็บเซอร์วิสเชื่อมกับระบบอื่นของสถาบัน

🔑ใครทำอะไรได้บ้าง

Moodle คุมสิทธิ์ด้วยบทบาท คนหนึ่งคนมีบทบาทต่างกันในแต่ละรายวิชาได้ เช่น เป็นครูในวิชาหนึ่งและเป็นผู้เรียนในอีกวิชา ตารางนี้คือบทบาทมาตรฐาน ผู้ดูแลระบบสร้างบทบาทเพิ่มได้

บทบาทตัวอย่างผู้ใช้แก้ไขรายวิชาตรวจงานส่งงาน
🧑‍💼 ผู้จัดการเจ้าหน้าที่ที่ดูแลหลายรายวิชาทั้งระบบหรือทั้งคณะได้ได้ไม่ได้
🛠️ ผู้สร้างรายวิชาเจ้าหน้าที่ที่ได้รับอนุญาตให้สร้างรายวิชาใหม่ได้ได้ไม่ได้
👩‍🏫 ครูอาจารย์ผู้สอนและดูแลรายวิชาได้ได้ไม่ได้
🧑‍🏫 ครูผู้ช่วย (แก้ไขไม่ได้)ผู้ช่วยสอนที่ตรวจงานไม่ได้ได้ไม่ได้
🎒 นักเรียนผู้เรียนที่ลงทะเบียนแล้วไม่ได้ไม่ได้ได้
👀 ผู้เยี่ยมชมผู้ที่เข้ามาดูได้แต่ร่วมกิจกรรมไม่ได้ไม่ได้ไม่ได้ไม่ได้

🌱จากโครงการวิจัยสู่แพลตฟอร์มทั่วโลก

  1. 💡 1999

    จุดเริ่มต้น Martin Dougiamas ใช้ WebCT ที่มหาวิทยาลัย Curtin เมืองเพิร์ท ออสเตรเลีย แล้วเริ่มสร้างทางเลือกแบบเปิด บนแนวคิดว่าการเรียนรู้เกิดจากการสร้างความรู้ร่วมกัน

  2. 🎉 2002

    Moodle 1.0 เปิดตัว ในเดือนสิงหาคม เป็นซอฟต์แวร์โอเพนซอร์สที่ใช้ได้ฟรี

  3. ⚙️ 2010

    Moodle 2.0 ปรับระบบไฟล์ใหม่ เพิ่ม Repository API และรองรับปลั๊กอินได้กว้างขึ้นมาก

  4. 📱 2013

    แอป Moodle เปิดตัว ทำให้เข้ารายวิชาจากโทรศัพท์และแท็บเล็ตได้

  5. ✨ 2022

    Moodle 4.0 ออกแบบเมนูและหน้ารายวิชาใหม่โดยยึดผู้เรียนเป็นหลัก

  6. 🌟 2025

    Moodle 5.0 สานต่อรอบการออกรุ่นปีละสองครั้ง และมีรุ่นสนับสนุนระยะยาวสำหรับสถาบันที่อัปเกรดไม่บ่อย

🚀เริ่มใช้งานได้สองทาง

  1. เข้าสู่ระบบ Moodle ของสถาบัน แล้วเปิดรายวิชาของคุณ
  2. เปิดโหมดแก้ไข ด้วยสวิตช์ด้านบนของหน้ารายวิชา
  3. เพิ่มทรัพยากร เช่น ใส่แนวการสอนเป็นไฟล์ในหัวข้อแรก
  4. เพิ่มกิจกรรม เช่น กระดานสนทนาให้แนะนำตัว หรืองานที่มอบหมาย
  5. ดูสมุดคะแนน และรายงานความคืบหน้าระหว่างที่ผู้เรียนทำงาน
  1. เลือกที่โฮสต์ เซิร์ฟเวอร์ของตัวเอง พันธมิตร Moodle หรือ MoodleCloud
  2. ติดตั้ง Moodle พร้อม PHP เว็บเซิร์ฟเวอร์ และฐานข้อมูล
  3. ตั้งค่าการยืนยันตัวตน เช่น สร้างบัญชีเอง LDAP หรือ single sign-on
  4. สร้างหมวดหมู่และรายวิชา แล้วลงทะเบียนผู้ใช้เข้ารายวิชา
  5. วางแผนอัปเกรด ตามปฏิทินการออกรุ่น และสำรองข้อมูลเป็นประจำ
